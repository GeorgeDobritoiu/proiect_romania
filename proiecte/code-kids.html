CODE Kids — programare în comunitate

Programare gratuită pentru copii, prin biblioteci și comunități locale.

Fundația Progress

Prezentare editorială a unei inițiative existente. Programul aparține organizatorului indicat; nu anunțăm un parteneriat.

Ce oferă programul

CODE Kids este un program al Fundației Progress pentru educație digitală în mediul rural și urban mic. Copiii învață gratuit programare prin cluburi locale. Site-ul include harta cluburilor, informații despre deschiderea unui club și opțiuni pentru susținători.

Cum te poți implica

  1. Părinte: consultă harta cluburilor și întreabă coordonatorul local despre vârstă, program și locurile disponibile.
  2. Bibliotecă sau școală: folosește opțiunea „Deschide un club” de pe site-ul oficial. Confirmă condițiile și perioada în care sunt preluate solicitările.
  3. Companie: discută direct cu fundația despre echipamente, voluntariat sau sprijin pentru un club.

Pregătire locală — propunerea noastră

Înainte de a solicita un club, identifică o persoană de contact, un spațiu accesibil și echipamentele existente. Întreabă familiile ce intervale le permit participarea. Nu cumpăra echipamente înainte să confirmi cerințele organizatorului.

O solicitare utilă include localitatea, instituția, persoana responsabilă, numărul estimativ de copii interesați și resursele disponibile. Acestea sunt recomandări de pregătire, nu criterii oficiale de eligibilitate.
